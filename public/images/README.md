# Images Directory

Place all your image assets (e.g. logo, avatar, project screenshots, backgrounds) in this folder.

## Recommended Filenames:
- `avatar.png` / `avatar.jpg`: Your profile picture (used in the "About" section).
- `logo.png`: Custom navbar branding logo (if you decide to replace text logo).
- `project1.jpg` / `project2.jpg`: Custom screenshots for your highlighted works.
- `hero-bg.jpg`: Hero background image (if you switch to a custom background image).
